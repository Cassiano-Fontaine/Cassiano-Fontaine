## Sobre mim

Sou profissional de **Qualidade de Software desde 2018**, com experiência em testes manuais, automação, testes de APIs e análise de sistemas.

Meu foco profissional está em QA e Quality Engineering, mas também desenvolvo aplicações e trabalho com tecnologias de backend, frontend, bancos de dados e infraestrutura.

Gosto de entender como os sistemas funcionam, investigar problemas e buscar soluções que tornem o software mais confiável. Fora da rotina de testes, mantenho projetos próprios envolvendo desenvolvimento web, inteligência artificial, processamento de dados e jogos.
